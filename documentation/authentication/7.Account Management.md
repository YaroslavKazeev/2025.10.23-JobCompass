## Account Management Operations

### 1. Profile Updates

- **Personal Information**: Name, email, address
- **Avatar Upload**: Image file handling and storage
- **Contact Details**: Phone, location preferences
- **Validation**: Server-side input sanitization

### 2. Skills Management

- **Skill Categories**: Job search preferences
- **Skills Array**: Comma-separated storage
- **Normalization**: Consistent skill formatting
- **Validation**: Skill whitelist and format checking

### 3. Password Changes

- **Current Password**: Verification before change
- **New Password**: Strength requirements
- **Security**: Force logout after password change
- **Hashing**: Secure bcrypt storage

### 4. Account Deletion

- **Confirmation**: User confirms in dialog (no password required; uses authenticated token)
- **Data Cleanup**: Delete user (cascade removes favorites)
- **Client**: Dispatches LOGOUT and redirects to home on success
- **Privacy**: Complete data removal

## Security Features

### Input Validation

- **Server-Side Validation**: All inputs validated server-side
- **Sanitization**: Remove malicious content
- **Type Checking**: Ensure proper data types
- **Length Limits**: Prevent buffer overflow attacks

### Password Security

- **Current Verification**: Verify existing password via bcrypt.compare
- **Strength Requirements**: Validated server-side
- **Secure Hashing**: bcrypt

### Data Protection

- **Secure Deletion**: Complete data removal (cascade from user)
- **Client Session**: LOGOUT dispatched on successful delete
- **Privacy Compliance**: GDPR data deletion requirements

## Error Handling

### Profile Updates

- **400 Bad Request**: Invalid input data
- **401 Unauthorized**: Authentication required
- **500 Internal Server**: Database errors

### Password Changes

- **400 Bad Request**: Weak new password
- **401 Unauthorized**: Incorrect current password
- **500 Internal Server**: Update failures

### Account Deletion

- **401 Unauthorized**: No valid user ID in token
- **404 Not Found**: User not found or already deleted
- **500 Internal Server**: Deletion failures
